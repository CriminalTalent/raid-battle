# RAID 레이드 전투 웹앱

마스토돈과 구글 시트 없이, 내 컴퓨터에서 필요할 때만 켜서 쓰는 레이드 전투 웹앱입니다.
명중·회피·크리티컬 다이스, 정산 순서, 스킬·쿨타임·팀 패시브(관리자가 이름 지정)는 기존 전투봇(`battle/`) 코드를 **그대로** 불러와 계산합니다.

네 개의 창이 상단 메뉴로 이어져 있고, 한 창에서 바뀐 내용(행동 제출, 보스 행동, 체력 변화)은 다른 창에 곧바로 반영됩니다.

| 창 | 주소 | 하는 일 |
|---|---|---|
| 로비 | `/` | 진행 중인 레이드 목록, 관전·관리로 바로 가기 |
| 관전 | `/w/전투번호` (관리자가 복사해 주는 관전 링크) | 이름을 넣고 입장. 격자맵, 체력, 원형 타이머, 스킬·보스 전조 발동 알림, 전투 기록, 응원 버튼, 채팅 보기(보내기 없음) |
| 참여 | `/p/개인코드` (한 사람에 하나) | 시작 위치 직접 고르기, 스킬·회복 아이템 버튼으로 행동 제출, 채팅 |
| 관리자 | `/admin` (비밀번호 로그인) | 전투 시작(시작 체력), 진행자로 채팅·보스 행동·입력 마감·종료, 러너·크리쳐(보스몹)·보스 스킬·러너 스킬·아이템 편집, 비밀번호 변경 |

---

## 1. Ruby 설치 (처음 한 번만)
1. https://rubyinstaller.org/downloads/ 에 들어갑니다.
2. **WITHOUT DEVKIT** 아래 목록에서 `Ruby 3.3.x (x64)` 를 받아 설치합니다. 설치 화면은 전부 기본값으로 "Next"만 누르면 됩니다.

## 2. 프로그램 받기
1. https://github.com/CriminalTalent/RAID 에서 초록색 **Code** 버튼 → **Download ZIP**.
2. 받은 ZIP 파일을 원하는 곳에 압축 풀기.

## 3. 실행
- 압축 푼 폴더의 **`start.bat`** 을 더블클릭합니다.
- 검은 창에 **관리자 비밀번호**가 나오고, 잠시 뒤 관리자 페이지가 브라우저에 열립니다.
- 관리자 로그인은 12시간 유지되고, 5번 틀리면 10분 동안 잠깁니다. 관리자 → 설정에서 비밀번호를 바꿀 수 있어요.
- 관리자 비밀번호를 잊으면: 끈 상태에서 `app/data/raid.json` 을 메모장으로 열고 `"admin_key"` 값을 바꿔 저장하세요.
- 끄려면 검은 창을 닫으면 됩니다. 스탯과 체력은 `app/data/raid.json` 에 저장돼서 다음에 켜도 남아 있습니다.
  (진행 중이던 전투는 끄면 사라집니다.)

## 4. 다른 사람과 같이 하기 (선택)
내 컴퓨터에서만 보려면 이 단계는 필요 없습니다.
1. https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe 를 받습니다.
2. 받은 파일 이름을 **`cloudflared.exe`** 로 바꿔서 `start.bat` 과 같은 폴더에 넣습니다.
3. `start.bat` 을 켜 둔 상태에서 **`share.bat`** 을 더블클릭합니다.
4. 창에 나오는 `https://….trycloudflare.com` 주소를 복사해서, 관리자 페이지의 **공유 주소** 칸에 넣고 "적용".
5. 이제 참여자 링크를 복사해 보내면 됩니다. 관전 주소는 `그 주소/watch` 입니다.
   (공유 주소는 share.bat 을 켤 때마다 바뀝니다.)

## 4-1. 서버에 올려서 항상 켜 두기 (선택)
Ruby 표준 기능만 써서 따로 설치할 것이 없고, 저장소에 `Dockerfile` 과 `render.yaml` 이 들어 있습니다.
- **Render(render.com)**: New → Blueprint → 이 저장소 선택 → `RAID_ADMIN_PASSWORD` 칸에 관리자 비밀번호 입력 → 만들기.
  기본은 **무료(free) 플랜**이라 돈이 들지 않지만, 서버가 재시작·재배포되면 데이터가 처음 상태로 돌아가고 15분 동안 접속이 없으면 잠들어요(다음 접속 때 1분쯤 뒤 깸).
  데이터를 계속 남기려면 `render.yaml` 의 `plan: free` 를 `starter`(유료)로 바꾸고 `disk` 부분의 `#` 을 지우세요.
- **Docker가 있는 서버**: `docker build -t raid .` → `docker run -d -p 80:4567 -e RAID_ADMIN_PASSWORD=비밀번호 -v raid-data:/data raid`
- **Ruby가 있는 리눅스 서버**: `PORT=4567 RAID_DATA_DIR=/srv/raid RAID_ADMIN_PASSWORD=비밀번호 ruby app/run.rb`

| 환경 변수 | 뜻 |
|---|---|
| `PORT` | 열 포트. 주면 외부 접속(0.0.0.0)으로 열림 |
| `RAID_DATA_DIR` | 데이터(raid.json, 이미지) 폴더. 서버의 영구 디스크 경로로 |
| `RAID_ADMIN_PASSWORD` | 관리자 비밀번호. 주면 켤 때마다 이 값으로 맞춤 (관리자 화면에서 바꿔도 재시작하면 이 값으로 돌아감) |

서버 주소가 생기면 share.bat 은 필요 없고, 관리자 화면의 참여자·관전자 링크가 그 주소로 바로 만들어집니다.

## 5. 전투 진행 순서
1. 관리자 → 러너 / 크리쳐 (보스몹) / 보스 스킬 / 러너 스킬 메뉴에서 추가·수정하고 저장 (연습용 예시가 들어 있음)
   - 이미지: 러너 두상과 보스 이미지는 "사진 올리기"로 넣어요(정사각형으로 잘려 `app/data/img` 에 저장). 다른 컴퓨터로 옮길 때는 `app/data` 폴더째 복사하세요.
   - 보상: 크리쳐 메뉴에서 승리 보상과 패배 시 압수할 크레딧(참여자 1명당)을 정해요. 러너의 크레딧은 러너 메뉴에서 보고 고칠 수 있어요.
   - 아이템: 회복 아이템은 전투 중 [아이템 이름/대상]으로 1명 회복(사거리 제한 없음, 정산 때 소지품에서 1개 차감). 무기·갑옷·장신구는 러너 메뉴에서 착용시키면 전투 스탯에 보너스가 더해집니다.
   - 러너 스킬은 "효과"로 계산돼요. 이름을 바꾸거나 같은 효과로 배율·사거리만 다른 스킬을 새로 만들어도 기존 규칙대로 계산됩니다.
2. 전투 진행 탭 → 참여자 추가(드롭다운), 시작 체력(HP), 크리쳐 선택 → **전투 시작** → 참여자 링크와 관전자 링크 보내기
3. 참여자: 격자에서 시작 칸 클릭 (준비 라운드)
4. 1라운드는 기존 규칙대로 보스 전체공격 고정
5. 매 라운드: 참여자 행동 제출 → 전원 제출 또는 5분 경과 시 자동 정산 → 관리자가 보스 행동 지정 (또는 "보스 자동 행동" 켜기)
6. 크리쳐 격파 / 전원 전투불능 / 관리자 "전투 종료" 시 끝

## 폴더 구조
```
start.bat / share.bat   Windows 실행 파일
app/                    웹앱 (엔진, 웹서버, 페이지)
  engine.rb             battle/ 의 규칙 코드를 불러와 라운드 진행
  local_sheet.rb        구글 시트 대신 data/raid.json 을 읽고 쓰기
  public/               관리자·참여자 페이지
  data/sample.json      처음 켤 때 복사되는 예시 데이터
battle/                 기존 전투봇 (규칙 코드 원본, TH3V151T0R5_B)
scout/                  기존 조사봇 (보관용, TH3V151T0R5_F)
```
