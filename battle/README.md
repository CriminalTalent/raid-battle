# RAID — 웹 레이드 전투

여러 명의 러너가 한 팀이 되어 보스 한 마리와 격자 위에서 싸우는 턴제 전투입니다.
진행자(관리자), 참여자(러너), 관전자가 각자 다른 주소로 들어오며, 모든 화면이 실시간으로 이어져 있습니다.

---

## 한눈에 보기

| 누가 | 주소 | 하는 일 |
|---|---|---|
| 진행자 | `/admin` | 전투를 만들고, 보스 행동을 정하고, 러너·보스·스킬·아이템·팀을 관리 |
| 러너 | `/p/<개인 링크>` | 내 캐릭터 확인, 시작 위치 선택, 매 라운드 행동 제출, 채팅 |
| 관전자 | `/w/<전투 번호>` | 이름을 넣고 입장, 전투 관람, 응원 버튼 (채팅은 보기만) |
| 누구나 | `/` | 로비: 진행 중인 전투 목록 |

화면 오른쪽 위 버튼으로 라이트·다크 모드를 바꿀 수 있습니다.

---

## 전투 흐름

1. **전투 만들기** (진행자)
   - 상대 보스와 참여할 러너를 고르고 시작 HP를 정합니다.
   - 시작 HP에는 지난 전투에서 남은 체력이 기본으로 들어갑니다.
   - 참여 인원 제한은 없습니다.
2. **링크 보내기**: 러너마다 개인 링크가 하나씩 나오고, 관전 링크는 모두 같습니다.
3. **캐릭터 확인과 준비 완료** (러너)
   - 링크를 열면 내 캐릭터 카드가 보입니다. 두상, 역할, 건강, 스탯, 팀·패시브, 스킬, 장비, 소지품이 나옵니다.
   - 내용이 맞으면 "확인했어요"에 체크하고 **준비 완료**를 누릅니다.
   - 틀린 곳이 있으면 채팅으로 알리면 됩니다. 진행자가 고치면 카드에 바로 반영됩니다.
4. **전투 시작** (진행자): 누가 준비됐는지 보고 시작합니다. 이때부터 타이머가 돕니다.
5. **시작 위치 고르기**: 격자 빈칸을 누르고 "이곳에 서겠습니까?"에서 Yes를 누릅니다. 자리를 고르기 전에는 격자에 보이지 않습니다.
6. **라운드 진행**
   - 보스의 전조와 표적이 화면에 크게 뜹니다. 예: "◎ 표적 · 벨라"
   - 러너는 제한 시간(기본 5분) 안에 행동을 하나 제출합니다.
   - 모두 제출하거나 시간이 끝나면 정산합니다. 제출하지 않은 사람은 그 턴을 잃습니다.
   - 2라운드부터는 진행자가 보스 행동을 정합니다. 자동 모드를 켜면 보스가 스스로 고릅니다.
7. **결과**
   - 보스를 쓰러뜨리면 승리, 러너가 모두 쓰러지면 패배입니다.
   - 결과 창에 승리자가 나오고, **전투 기록 보기**로 처음부터 다시 볼 수 있습니다.

## 러너 화면 사용법

- **스킬 버튼**을 누르면 마우스 옆에 필요한 것만 차례로 뜹니다.
  - 대상이 필요하면 러너 목록이 뜹니다. 체력이 같이 보이고, 사거리 밖이면 "멀어요"가 붙습니다.
  - 칸이 필요하면 (이동 등) 격자에서 칸을 누릅니다.
  - 마지막으로 "회복 → 아린, 사용하시겠습니까?"에서 Yes를 누르면 제출됩니다.
- 스킬 버튼에 마우스를 올리면 사거리가 격자에 파랗게 표시됩니다.
- 격자 위 캐릭터 머리 위에는 체력바가 있습니다. 30% 이하가 되면 빨갛게 바뀝니다.
- 보스 머리 칸에는 바라보는 방향이 큰 화살표로 표시됩니다.

## 전투 기록

행동은 제출하는 순간 기록에 남고, 정산 결과가 이어서 붙습니다.

```
아린 입장
아린 준비 완료
진행자가 전투를 시작했습니다. 시작 위치를 고르세요.
아린 > 시작 위치 D3
애셔 그레이 > 심핵 공격 예정
벨라 > 아린 회복 예정
아린 > 이동(C2) 예정
[1라운드] … 전투 결과
```

## 기본 규칙

### 격자와 이동

- 격자는 가로 A~G, 세로 1~8입니다.
- 이동은 가로·세로·대각선으로 **1칸**, 빈칸으로만 갈 수 있습니다.
- 보스는 여러 칸을 차지할 수 있습니다(1x1 ~ 3x3). 위치 칸(머리)과 바라보는 방향(상·하·좌·우)이 있습니다.

### 판정

- 명중률 = 60 + 기술 (%)
- 회피율 = 대상 민첩 × 1%
- 크리티컬률 = 행운 × 1%
- 확률은 모두 0~100%로 제한됩니다. 스킬에 따로 정해진 값이 있으면 그 값을 씁니다.

### 체력

- 최대 체력을 넘게 회복되지 않습니다.
- 깎인 체력은 다음 전투로 이어집니다. 진행자가 HP를 고치거나 전원 회복을 눌러 회복시킵니다.

### 역할

러너는 **수호 / 공격 / 지원** 중 하나의 역할을 가집니다. 역할은 표시와 보스 대상 지정(예: 수호 역할 전원)에 쓰입니다.

### 대표 스킬

| 스킬 | 효과 |
|---|---|
| 공격 | 단일 공격 (마법능력 × 배율) |
| 방어 | 명중 판정 없이 내구도 강화 |
| 회피 | 자신의 민첩 강화 |
| 회복 | 가까운 아군 한 명 회복 |
| 이동 | 1칸 이동 |
| 관찰 | 행동하지 않음 |
| 보호 | 보호막 부여. 라운드가 지나도 남고, 다시 쓰면 누적 |
| 강화 | 마법능력 버프. 중첩되지 않음 |
| 희생 | 지정한 아군 대신 맞기. 맞는 쪽도 회피 판정 가능 |
| 고육지책 | 건강을 소모한 만큼 마법능력을 올려 공격. 반드시 명중, 전투 중 1회 |

모두에게 보이는 기본 스킬 외에, 진행자가 러너마다 **전용 스킬**을 더 넣어 줄 수 있습니다.

### 아이템

- **회복 아이템**: 전투 중 아군 한 명에게 씁니다. 사거리 제한은 없고, 쓰면 1개 줄어듭니다.
- **장비**: 착용하면 스탯 보너스가 붙습니다(예: 가죽 갑옷 내구도 +3).
- 아이템은 진행자가 러너에게 넣어 줍니다.

### 팀과 패시브

러너는 팀에 속하고, 팀이 가진 패시브 두 개 중 하나를 고릅니다. 팀 이름과 패시브는 진행자가 정합니다.

| 패시브 | 효과 |
|---|---|
| 정면 수호 | 보스 정면 1칸에 서 있으면 내구도 +50% |
| 역경 | 건강이 40% 미만이면 마법능력 +50% |
| 무결 | 이전 라운드에 피해가 없었으면 마법능력 +50% |
| 관망 | 관찰하면 다음 라운드부터 행운 +10 |
| 통찰 | 보스가 상태이상이면 마법능력 +50% |
| 변통 | 직전 라운드와 다른 분류의 행동을 하면 기술 +10 |
| 인내 | 이전 라운드에 맞았으면 내구도 +50% |
| 불굴 | 전투 중 1회, 건강이 0 이하가 되는 것을 막음 |

### 보스

- 보스 스킬 범위: **전체**, **주변N**(머리 기준 N칸 안), **전방N**(바라보는 방향 N칸), 빈칸이면 무작위 대상입니다.
- 진행자가 대상 러너나 범위 칸을 직접 고를 수도 있습니다.
- 보스마다 쓰는 스킬 목록, 고정 스킬, 이미지를 정할 수 있습니다.

### 크레딧

- 승리하면 참여자 전원이 보스에 정해진 **보상 크레딧**을 받습니다.
- 패배하면 정해진 **압수 크레딧**만큼 빠지고, 모자라면 마이너스가 됩니다.

## 진행자 페이지

| 메뉴 | 할 수 있는 것 |
|---|---|
| 전투 진행 | 전투 만들기, 링크 복사, 준비 현황, 전투 시작, 보스 행동 지정, 자동 모드, 입력 마감, 종료, 진행자 채팅 |
| 러너 | 이름, 팀·패시브, 체력·스탯, 역할, 크레딧, 장비, 소지품, 두상, 전용 스킬 |
| 크리쳐 (보스) | 위치·크기·방향, 스탯, 쓰는 스킬, 보상·압수 크레딧, 이미지 |
| 보스 스킬 / 러너 스킬 | 스킬 추가·수정, 범위·배율·쿨타임 등 |
| 아이템 | 회복 아이템과 장비 추가 |
| 팀 | 팀 이름과 패시브 |
| 설정 | 비밀번호 변경, 로그아웃 |

진행자 페이지는 비밀번호로 보호됩니다. 5번 틀리면 10분 동안 잠깁니다.

---

## 실행

```
ruby app/run.rb
```

Windows에서는 `start.bat`을 실행하고 브라우저에서 `http://localhost:4567`을 엽니다.
데이터는 `app/data/raid.json` 한 파일에 저장됩니다.
