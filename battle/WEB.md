# 레이드 웹 페이지

RAID는 혼자 돌아가는 웹앱입니다. Ruby만 있으면 되고, 따로 설치할 라이브러리나 외부 서비스가 필요 없습니다.
진행자, 러너, 관전자가 각자 다른 주소로 들어오며, 한 화면에서 바뀐 내용은 다른 화면에 곧바로 반영됩니다.

---

## 페이지 주소

| 주소 | 페이지 | 내용 |
|---|---|---|
| `/` | 로비 | 진행 중인 전투 목록, 각 페이지로 가는 입구 |
| `/admin` | 관리자 | 비밀번호 로그인. 전투 만들기·진행, 러너·크리쳐·스킬·아이템·팀 편집 |
| `/p/<개인 링크>` | 참여자 | 러너 한 명 전용. 캐릭터 확인, 준비 완료, 위치 선택, 행동 제출, 채팅 |
| `/w/<전투 번호>` | 관전자 | 이름을 넣고 입장. 격자, 체력, 타이머, 전투 기록, 채팅 보기, 응원 버튼 |
| `/watch` | 관전자 | 전투를 고르는 관전 입구 |
| `/img/...` | 이미지 | 관리자가 올린 러너 두상과 크리쳐 이미지 |

- 참여자 링크는 전투를 만들 때 러너마다 하나씩 생깁니다. 링크를 가진 사람만 그 러너로 행동할 수 있습니다.
- 관전 링크는 모두 같은 주소를 씁니다.
- 모든 페이지는 라이트·다크 모드를 지원합니다.

---

## 실시간 연결

- 서버는 무언가 바뀔 때마다 "변경 번호"를 하나씩 올립니다.
- 각 화면은 `/api/wait`로 다음 변경이 생길 때까지(최대 20초) 기다렸다가, 바뀌면 새 상태를 받아 다시 그립니다.
- 한 브라우저에서 탭을 여러 개 열어도 기다리는 연결은 하나만 쓰고, 나머지 탭은 그 결과를 나눠 받습니다.
- 연결 상태는 화면 오른쪽 위 점으로 표시됩니다(초록 = 실시간 연결).

---

## API

화면이 내부적으로 쓰는 주소입니다. 보통은 직접 부를 일이 없습니다.

### 공개

| 메서드 | 주소 | 내용 |
|---|---|---|
| GET | `/api/battles` | 전체 전투 상태 (격자, 체력, 단계, 기록, 채팅, 응원, 화면 연출 이벤트) |
| GET | `/api/wait?v=<번호>` | 변경이 생길 때까지 기다렸다가 새 변경 번호를 돌려줌 |

### 참여자 (개인 링크의 토큰 `t` 필요)

| 메서드 | 주소 | 내용 |
|---|---|---|
| GET | `/api/play?t=` | 내 화면 정보 (단계, 내 캐릭터 카드, 스킬, 아이템, 제출 상태) |
| POST | `/api/ready` | 준비 완료 / 준비 취소 |
| POST | `/api/play` | 시작 위치 또는 행동 제출 |
| POST | `/api/chat` | 채팅 보내기 |

### 관전자

| 메서드 | 주소 | 내용 |
|---|---|---|
| POST | `/api/watch/hello` | 이름 등록 |
| POST | `/api/cheer` | 응원 버튼 |

### 관리자 (로그인 쿠키 필요)

| 메서드 | 주소 | 내용 |
|---|---|---|
| POST | `/api/login`, `/api/logout` | 로그인 / 로그아웃 |
| GET | `/api/admin` | 관리 화면 데이터 (표 전체, 진행 중인 전투, 참여 링크) |
| POST | `/api/admin/table` | 러너·크리쳐·스킬·아이템·팀 표 저장 |
| POST | `/api/admin/heal` | 러너 전원 체력 회복 |
| POST | `/api/admin/start` | 전투 만들기 (대기실 상태로 생성) |
| POST | `/api/admin/begin` | 전투 시작 (시작 위치 선택으로 넘어감) |
| POST | `/api/admin/boss` | 크리쳐 행동 지정 (스킬, 대상 러너, 범위 칸) |
| POST | `/api/admin/auto` | 크리쳐 자동 행동 켜기·끄기 |
| POST | `/api/admin/settle` | 입력 마감 (바로 정산) |
| POST | `/api/admin/end` | 전투 종료 |
| POST | `/api/admin/chat` | 진행자로 채팅 |
| POST | `/api/admin/password` | 관리자 비밀번호 변경 |

## 실행

```
ruby app/run.rb
```

- Windows에서는 `start.bat`을 두 번 눌러 실행합니다.
- 켜지면 창에 관리자 주소와 관리자 비밀번호가 나옵니다.
- 브라우저에서 `http://localhost:4567`을 엽니다.

### 같은 PC가 아닌 사람과 함께 하기

- `share.bat`을 실행하면 바깥에서 들어올 수 있는 `https://….trycloudflare.com` 주소가 생깁니다. 이 기능은 같은 폴더에 `cloudflared.exe`가 있어야 합니다.
- 그 주소를 관리자 페이지의 **공유 주소** 칸에 넣고 적용을 누르면, 참여자·관전 링크가 그 주소로 바뀝니다.
- 창을 닫으면 공유가 끝납니다.

## 환경 변수 (선택)

| 이름 | 기본값 | 내용 |
|---|---|---|
| `RAID_PORT` / `PORT` | `4567` | 서버 포트. `PORT`를 주면 바깥 접속(`0.0.0.0`)으로 열림 |
| `RAID_HOST` | `127.0.0.1` | 열 주소를 직접 정할 때 |
| `RAID_DATA_DIR` | `app/data` | `raid.json`과 이미지 폴더(`img/`) 위치 |
| `RAID_ADMIN_PASSWORD` | (자동 생성) | 관리자 비밀번호. 주면 켤 때마다 이 값으로 맞춤 |
| `RAID_ACTION_SECONDS` | `300` | 행동·시작 위치 입력 제한 시간(초) |

## 데이터

- 모든 데이터는 `raid.json` 한 파일에 저장됩니다.
  - 러너, 크리쳐, 크리쳐 스킬, 러너 스킬, 아이템, 팀 표
  - 설정 (관리자 비밀번호)
- 업로드한 이미지는 같은 폴더의 `img/`에 저장됩니다.
- 진행 중인 전투, 채팅, 응원은 메모리에만 있고, 끝난 전투는 1시간 뒤 목록에서 사라집니다.
- 전투로 바뀐 러너 체력과 골드는 `raid.json`에 바로 저장됩니다.

## 보안

- 관리자 기능은 로그인 쿠키(12시간 유지)로만 쓸 수 있습니다.
- 같은 접속지에서 5번 틀리면 10분 동안 잠깁니다.
- 참여자 링크는 추측하기 어려운 무작위 토큰입니다. 다른 사람에게 넘기면 그 사람이 대신 행동할 수 있으니 본인에게만 보냅니다.
